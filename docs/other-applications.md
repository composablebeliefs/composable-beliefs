# Other applications

This essay has been consolidated. Composable Beliefs is a general mechanism; applications of it are documented at a deliberate distance from the mechanism itself:

- **Durable, auditable reasoning for AI agents** - rules as beliefs with provenance, staleness cascades, and the compiled `CLAUDE.md`: [chapter 3, operating the graph](guide/3-operations.md). This is the framework's own primary use.
- **Codepaths** - code tours that cannot rot: [chapter 4, code, anchors, positions](guide/4-code.md).
- **The eval ledger** - grounding model-evaluation findings: [case-studies/eval-ledger.md](case-studies/eval-ledger.md).

The original essay's forward-looking material (the "three faces" framing) is archived in [deprecated/docs/](../deprecated/docs/README.md).
