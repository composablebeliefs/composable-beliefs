Finalize and persist the session's thread: synthesize metadata and the operator-facing narrative section onto the live render, conform it to the thread shape, register it in the nursery, and commit it with the session's work. The thread document is the single persisted close artifact (cb:b578); no separate chronicle is written - the chronicles shelf is closed and archived at `deprecated/chronicles/`.

The Stop hook (`.claude/hooks/transcript_hook.py`, registered in the committed `.claude/settings.json`) rewrites a responses-only render plus a raw jsonl copy into `beliefs/nursery/threads/.sessions/` every turn, in local and remote sessions alike, and stages the render so it rides along with the session's commits - a crash-safe draft lane that persists even if this skill never runs. `/end` is the finalization on top: it turns the live render into a curated, registered thread doc.

**Threads are not provenance.** The nursery proto-belief documents are; a belief grounds in a proto-belief document, never in a transcript (`beliefs/nursery/threads/index.md`). A thread exists for crash safety and human reading.

## When to run `/end` (cb:b583)

**Run `/end` alone, in its own turn.** The Stop hook's render only ever reaches the *previous completed* turn, so `/end` running *inside* a turn cannot capture that turn - the recurring cb:b518 tail-gap. Do the session's substantive close work first (mint, retro-pair, surface updates, commits); then invoke `/end` as its own separate exchange, with no other substantive work in the same turn. Run this way, the render has advanced to include the close, so the finalized body is complete through it; the only omitted turn is this `/end` turn itself, which carries no decision content and needs no disclosure.

**If `/end` is being run inline** - in a turn that also did substantive close work - stop and warn the operator: the current turn will not be captured in the finalized body, and they should re-run `/end` in a fresh turn to capture it. Emit this standing caution whenever close work preceded `/end` in the same turn. A same-turn `/final`-style "run the close and finalize together" does not satisfy this (a turn boundary is a separate exchange, not a second skill call) - it reproduces the tail-gap.

## Steps

1. **Locate the live render** in `beliefs/nursery/threads/.sessions/` (`<date>-<session>.md`, with `<date>-<session>.jsonl` beside it). If the hook was not running (no render exists), fall back to hand-capturing from context in the same format - disclose that in the doc's blockquote, as the existing hand-captured threads do.

2. **Synthesize the metadata the hook cannot know.** Frontmatter: `type: thread`, `title` (`<date> - <short arc name>`), `description` (what the session covered and when to read it), `tags` (include `thread`), `status: active`, `timestamp` (today), `artifact: session:<date>-<slug>`. These are only knowable at session end; the hook owns the live body, `/end` owns the metadata (transcript-format's pipeline).

3. **Open with the operator-facing narrative section** (cb:b578), then conform the body to the thread shape (`2026-06-25-belief-audit.md` is the prototype for the receipts register below it): the frontmatter above, a capture-provenance blockquote (hook-rendered or hand-captured), the narrative section - where things stood, the arc with its incidents as story beats, where things stand now, and what the next session inherits, narrative carrying the load and ids subordinate (this is the register the retired chronicles held; it absorbs the old `## Where we are` digest) - then the turn-by-turn body, and a `## Related` section linking the proto-belief documents and beliefs the session fed.

   **The capture-provenance blockquote states the true boundary and never overstates (cb:b584).** When `/end` ran alone in its own turn, note that the embedded body is complete through the session's close and only this finalization turn is omitted. When `/end` ran inline (against the standing caution), note explicitly that the body covers only through the previous completed turn and the close turn is not transcribed. Never write a note that claims the body reaches a turn the body does not contain - the fold-chronicle close overstated by one full topic, and that is the failure this note prevents.

4. **Synthesize the routing ledger** (cb:b572) - every persisted thread carries one. After the narrative section, a `## Routing` table with one row per topic the thread touched: the strand state (open, paused, closed), the dispatch pointer (the proto-belief document the strand's content routed to, or unrouted), and the dangling question when one is pending. Pointers and states only - synthesized content always lands in the proto-belief documents, never in the ledger, so it cannot become a digest of the thread. A multi-topic thread is resumed by reading its ledger (`2026-07-02-authoring-pipeline.md` carries the first instance).

5. **Retro-pair before writing (cb:b507).** Choose the destination slug first, then append a `document:beliefs/nursery/threads/<date>-<slug>.md` evidence entry to every belief this session minted (through `mix cb.evidence`), and only then write the doc - the pairing lands inside the record it cites instead of dangling after the close. The citation points at a file a few minutes younger than it; push after both land, and the document-rung verifier (cb:b571, when built) must check at push granularity to keep this ordering legal. Because `/end` runs in its own turn, the retro-pairing has already happened in the substantive close turn(s) before this one - confirm it landed rather than doing it here.

6. **Write and register.** Write to `beliefs/nursery/threads/<date>-<slug>.md`. Add it to the threads index (`threads/index.md` Contents) and the nursery `manifest.json` (bump `count`, add the entry with the `session:` artifact). Back-link it from any proto-belief documents the session fed (their `threads:` frontmatter).

7. **Leave the raw jsonl in `.sessions/`, uncommitted.** Committing raw is gated on transcript-format's repo-weight decision (the LFS lean); until that lands, the render is the committed lane and the raw copy is working-area only. Do not delete it.

8. **Commit and push** the thread doc, index, and manifest together with the session's work - per the repo's git policy, only when the user has instructed the commit (invoking `/end` for a session whose work is being pushed is that instruction for the thread that records it).
