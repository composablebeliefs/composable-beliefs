# docs/ - archived essays and dated records (2026-07-06)

This shelf holds documentation moved out of `docs/` in the 2026-07-06 refactor, which reorganized the live docs surface around the guide (`docs/guide/`) and the mission statement it opens with. Files here are archived untouched, in the state they had when moved; they are history, not current documentation.

What landed here, and why:

- **Superseded essays** - `composable-beliefs-thesis.md`, `actualization.md`, `cb-on-the-beam.md`, `operations-vs-artifacts.md`. Written against earlier schema vocabularies (assertion/primitive/compound/implication/directive, `confidence`) and earlier framings of the project; the guide is the current treatment of everything they cover.
- **Draft specs** - `belief-shell/`. The 2026-03 belief-shell drafts; tier 1 shipped as `mix bs`, the rest predates the current schema.
- **Dated analyses and field notes** - `analyses/`, `2026-06-01-shared-provenance-shallow-clone-parable.md`, `2026-06-23-docs-vs-code-audit.md`. Point-in-time records, kept as records.
- **The guide's former capstone** - `8-beyond-the-ledger.md`. A forward-vision chapter (the three-faces ladder); the live docs describe what the system is, not where it could go.

Removal stays gated the same way as `deprecated/chronicles/`: where the graph cites one of these files as an evidence artifact, a stub remains at the old `docs/` path (currently `docs/2026-06-23-docs-vs-code-audit.md`), and deleting archived material requires first repointing or retiring the citing evidence.
